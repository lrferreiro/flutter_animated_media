# Animated media gallery

A standalone example of Unicode emoji playback, a searchable Noto catalog,
category filters, selection, preview controls and an original custom catalog.
The custom catalog includes a vector pulse and a two-frame GIF, both MIT-licensed.

The example demonstrates embedding the picker in a page without chat-specific
models, navigation or network credentials. The information action opens the
license screen, including Noto attribution and the full CC BY 4.0 text.
